# Mes Recettes

Petite app perso pour importer des recettes de cuisine depuis une photo ou un site web,
grâce à l'IA (Claude), et les garder synchronisées via ce dépôt GitHub.

- Les recettes sont stockées en JSON dans le dossier `/recipes`.
- Aucune donnée ne transite par un serveur autre que GitHub et l'API Anthropic.
- Ta clé API et ton jeton GitHub restent uniquement dans le navigateur (localStorage).

Voir les instructions de mise en place fournies séparément.
